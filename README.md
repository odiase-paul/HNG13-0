# Frontend Wizards – Stage 0 Task: Profile Card

A simple, accessible, and responsive profile card built with semantic HTML, CSS, and vanilla JavaScript.  
This project is designed to meet the Frontend Wizards Stage 0 task requirements.

## features

- Semantic HTML structure (article, figure, nav, section)
- Accessible design (alt text, aria labels, focus styles)
- Responsive layout using Flexbox
- Displays live time in milliseconds
- Avatar image upload support
- Social links open in new tabs

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
