# Frontend Wizards – Stage 0 Task: Profile Card

A simple, accessible, and responsive profile card built with semantic HTML, CSS, and vanilla JavaScript.  
This project is designed to meet the Frontend Wizards Stage 0 task requirements.

## features

- Semantic HTML structure (article, figure, nav, section)
- Accessible design (alt text, aria labels, focus styles)
- Responsive layout using Flexbox
- Displays live time in milliseconds
- Avatar image upload support
- Social links open in new tabs

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

##### STAGE TWO(2) TASK

# Project Title: Contact & About Me Pages

- This task is continuation from stage 0 but featuring two fully accessible, semantic, and testable pages(contact us and About me) built with HTML, CSS, and vanilla JavaScript.

## Contact me

- A simple and accessible contact form that validates user input before submission.

# features

- Field: Full Name, Email, Subject, Message, Submit Button, Error Messages, Success Message.

# instruction

- Each input is linked to a <label> using the for attribute.
- Error messages are associated with their respective input using aria-describedby.
- The entire form is fully keyboard navigable.

## About us

- A reflective page to share your thoughts and self-assessment as part of your learning journey.

# features

- Sections: Bio, goals in this program, areas of low confidence, note to future self, extra thoughts

# Structure

- Wrapped with `<main data-testid="test-about-page">`
- Each section is contained in a <section> tag.
- Proper headings used `(<h1>, <h2>)` for clarity and accessibility.
- Fully responsive layout for mobile, tablet, and desktop screens.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
